# 信号灯 SignalLight · 产品规划（加密市场 v1）

> 定位：**给新手的“技术分析翻译器”**。把专业指标翻译成一句人话的结论，每个结论都附上历史胜率和风险位，让小白知道“现在怎样、为什么、以前灵不灵、错了在哪认错”。

---

## 1. 竞品拆解：TradingSignal.pro

| 模块 | 它的做法 | 对新手的问题 |
|---|---|---|
| TD 序列 | Setup 9 / Countdown 13 / TDST / Risk Level，多周期表 | 术语密集；“4/9”“qualified13”小白看不懂 |
| 技术分析 | 约 39 个指标，分 6 类（趋势/动量/波动/量能/形态/支撑阻力），给多空票数、历史共振点 | 39 张卡片，信息过载，没有“所以呢？” |
| 关键支撑阻力 | 多周期、多方法（Pivot、Fib、成交量分布、AVWAP、均线、整数位等）按价位聚类 | 实测接口会报错（502）；新手不知道怎么用价位 |
| 趋势强弱 | 自研加权，0–100 强度 + 历史趋势线 | 只给分数，不说该怎么做 |
| 斐波那契 | 手动选 A/B 点，另有“自动节奏检测”（假设检验） | 手动选点对新手门槛高 |
| 缠论 / VCP / 威科夫 | 笔、中枢、买卖点；VCP 只做日线；威科夫的区间、阶段、事件 | 理论门槛最高，新手基本用不上 |
| AI 解读 / 专家点评 | LLM 生成多周期结论，专家人工写短评 | 仍然是“行话版”结论 |
| 筛选器 | 按预设条件选标的，免费版只看前 10 条 | 面向老手 |

**结论**：它是“专业工作台 + 面向 Agent 的 MCP 服务”，**目标用户是老手和 AI Agent**。新手市场是空位。

## 2. 我们怎么超越它（差异化）

1. **一句话结论 + 红绿灯**：每个币、每个周期只给一个状态（🟢偏多 / 🟡观望 / 🔴偏空），附 0–100 的综合分和信心等级。所有模块的结论都汇总到这里。
2. **“以前灵不灵”**：每个信号旁边直接显示在**这个币、这个周期**上的历史统计（出现次数、N 根 K 线后上涨的概率、平均涨跌幅）。竞品只在 AI 文案里提一句“复盘”。我们把它做成系统化、可验证的数据，诚实地告诉用户哪些信号其实不靠谱。
3. **错了在哪认错**：每个结论配好“关键支撑、关键阻力、建议止损参考位”，再加一个**仓位计算器**（输入本金和能承受的亏损比例，算出建议仓位），从第一天起培养风控习惯。
4. **人话翻译 + 术语点读**：默认“新手模式”只用大白话；每个术语都可以点开看“是什么 / 怎么看 / 常见误区”。“专业模式”保留完整数据，老手也能用。
5. **多周期一张图**：用短线、中线、长线三栏的信号灯矩阵，替代竞品那张专业的多周期表。
6. **首页就是答案**：首页是“今日看盘”，所有币的信号灯一屏看完，不用先学会操作工作台。
7. **算法放在服务端**：竞品的接口里能看到大量中间结果。我们只把展示要用的结果发给前端，评分权重等核心逻辑不暴露。

## 3. 用户与场景

- **主用户**：入门 0–1 年的加密新手。他们会用交易所 App，但看不懂指标。
- **核心问题**：现在能不能买？该在哪止损？这个信号可信吗？
- **次要用户**：有经验的交易者（专业模式）。

## 4. 信息架构（v1）

```
首页 /                 今日看盘：所有币的信号灯矩阵（1h / 4h / 1d）+ 市场温度
币种页 /coin/[symbol]  ├─ 总览（新手默认）：结论卡、多周期灯、关键价位、风控计算器、信号胜率
                       ├─ TD 序列        ├─ 指标共振     ├─ 支撑阻力
                       ├─ 趋势强度       ├─ 斐波那契（自动波段 + 手动）
                       └─ 缠论（笔 / 中枢 / 买卖点）
学堂 /learn            术语词典 + 每个方法的 3 分钟入门
```

## 5. 分析引擎（全部自研，按公开定义实现）

| 引擎 | 实现要点 |
|---|---|
| 数据 | Binance 公共行情镜像 → OKX 两级回退，服务端缓存（按周期设置 TTL） |
| 指标 | EMA/SMA、MACD、RSI、KDJ/Stoch、CCI、威廉、ROC、ADX/DMI、PSAR、Aroon、布林、ATR、Keltner、OBV、MFI、CMF、ADL、强力指数、量比、VWAP、一目均衡、K 线形态、背离检测 |
| TD 序列 | Setup 9（含完美 9）、TDST、Countdown 13（含第 13 根条件、取消与回收规则）、Risk Level |
| 支撑阻力 | 摆动高低点 + 成交量分布 POC/价值区 + 经典 Pivot + 整数关口 + 均线，按 ATR 聚类打分，并汇总多个周期 |
| 趋势强度 | 自研：方向票按 ADX 加权，输出 −100..+100 的连续曲线 |
| 斐波那契 | 用 ZigZag 自动识别最近的主波段，算回撤和扩展；也支持在图上手动点选 |
| 缠论 | 包含关系合并 → 分型 → 笔 → 中枢 → 一/二/三类买卖点（简化版） |
| 信号统计 | 对每类信号做历史前向收益统计：胜率、平均收益、样本数，样本不足时明确提示 |
| 综合评分 | 趋势 40% + 动量 25% + TD 时机 15% + 位置（距支撑阻力）20%，映射成红绿灯 |

## 6. 路线图

- **v1（本次）**：加密 10 个主流币；首页信号灯；币种页 7 个模块；新手/专业双模式；胜率统计；仓位计算器；术语词典。
- **v1.1**：价格和信号提醒（站内、邮件、Telegram）；自选币；PWA。
- **v1.2**：AI 解读（Claude，基于结构化快照生成人话版本，严格要求“不预测价格、必须给出风险”）。
- **v2**：模拟盘（用虚拟资金验证信号）、筛选器、VCP 与威科夫、股票和外汇市场。

## 7. 合规与边界

- 全站显著提示“仅供学习参考，不构成投资建议”。
- 不接入下单功能；不承诺收益；样本不足的统计必须标注。
- 数据来自交易所公开行情接口；不抓取、不复制竞品的数据或文案。
